# plm_website

# 🏫 Pralay Meas Primary School Website
### វែបសាយ​សាលាបឋមសិក្សា​ព្រាលម្មាស

A website for **Pralay Meas Primary School**, built with React Vite. The site presents the school's programs, teachers, class schedules, and contact information.

---


## 📁 Project Structure

```
plm_website/
├── public/                  # Static assets served directly
├── assets/                  # Images, icons, and media files
├── src/
│   ├── components/          # Reusable UI components
│   │   ├── Navbar.jsx       # Navigation bar with language toggle
│   │   ├── Hero.jsx         # Landing/hero section
│   │   ├── About.jsx        # About the school
│   │   ├── Academics.jsx    # Programs and academics overview
│   │   ├── Teachers.jsx     # Teacher profile cards
│   │   ├── Classes.jsx      # Class listing (Grades 1–6)
│   │   ├── ClassDetail.jsx  # Detailed view: schedule, results, cleaning
│   │   ├── Management.jsx   # School management/staff section
│   │   ├── News.jsx         # News & events section
│   │   ├── Contact.jsx      # Contact info and form
│   │   └── Footer.jsx       # Site footer
│   ├── data/
│   │   └── classData.js     # Grade 1–6 schedules, results, cleaning groups
│   ├── App.jsx              # Root component & routing logic
│   ├── main.jsx             # React entry point
│   └── index.css            # Global styles
├── index.html               # HTML entry point
├── vite.config.js           # Vite configuration
```
